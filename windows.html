Windows 앱 내려받기

PC 를 함께 관리하려면 그 PC 에 GuardPact Windows 앱을 설치하세요. 아래 단추는 늘 최신 설치 파일로 이어집니다.

휴대폰에서 이 쪽을 열었어요. 설치할 PC 에서 이 주소를 여세요.

guardpact.app/windows

Windows 앱 내려받기

설치 방법

  1. 받은 설치 파일(GuardPact-Setup-….exe)을 실행합니다.
  2. 「이 앱이 디바이스를 변경하도록 허용하시겠어요?」 창에서 「예」를 누릅니다(관리자 권한 설치).
  3. 설치가 끝나면 휴대폰 앱과 같은 계정으로 로그인합니다.

64비트 Windows 용입니다. 설치한 뒤에는 앱이 새 판을 스스로 받아 업데이트합니다.
