3. 민감 기능에 대한 처리 원칙

3.1 요청형 위치 및 구성원 주도 위치 제공

GuardPact는 지속적인 위치 추적과 지오펜싱을 제공하지 않습니다. 원격관리자가 요청할 때(요청형) 또는 구성원이 직접 실행할 때(구성원 주도 제공) 그때마다 현재 위치를 1회 처리하며, 위치 좌표는 받는 기기만 풀 수 있게 암호화해 임시 보관한 뒤 삭제합니다. 처리 방식, 보유 기간, 이용자 권리는 13. 위치정보 처리에 관한 사항을 따릅니다.

3.2 화면 캡처

휴대폰 화면 캡처는 구성원의 명시적 승인 없이 수행하지 않습니다. 비밀 원격 캡처는 지원하지 않습니다. PC(Windows) 화면 캡처는 유효한 원격관리 연결, 플랜, 운영체제 권한 범위 안에서 수행되며, 구성원이 원격관리자마다 정한 처리 방식(자동 응답, 동의(매번), 사용 거부)을 따릅니다. 기본값인 자동 응답에서는 구성원 승인 없이 캡처되며, 캡처 후 5초 안에 구성원이 전송을 거부할 수 있습니다. 캡처 이미지는 받는 기기만 풀 수 있게 암호화해 전달하며, 표시 완료 또는 임시 보관 시간(5분) 만료 후 삭제됩니다.

3.3 메시지와 암호화 콘텐츠

요청형 위치 좌표, 화면 캡처 이미지, 1:1 메시지는 받는 기기만 풀 수 있게 암호화해 전달하며, 회사는 그 내용을 볼 수 없습니다. 회사 서버는 전달과 상태 관리를 위해 암호문과 메타데이터만 처리합니다.

3.4 설치 앱 목록과 알림 접근

관리 대상 기기의 설치 앱/프로그램 목록은 원격관리자의 허용·차단 목록 설정, 앱별 정책 적용, 앱 설치 승인 기능 제공을 위해 수집되어 서버에 보관되며, 해당 기기에 연결된 원격관리자에게만 표시됩니다.

Android 알림 접근 권한은 원격관리자가 설정한 앱별 알림 차단 기능을 제공하기 위해서만 사용합니다. 차단 대상 판정은 기기 안에서 앱 패키지명 기준으로 수행되며, 알림의 제목·본문 등 내용은 수집, 전송, 저장하지 않습니다.

4. 만 14세 미만 아동의 개인정보

서비스가 만 14세 미만 아동의 개인정보를 처리하는 경우 회사는 법정대리인의 동의를 받거나 법령상 허용되는 절차를 따릅니다. 법정대리인은 아동의 개인정보 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다.

원격관리자는 본인이 아동의 법정대리인이거나 적법한 관리 권한을 가진 사람임을 확인해야 하며, 아동의 권리와 안전을 해치는 방식으로 서비스를 이용해서는 안 됩니다.

회사는 이용자의 개인정보를 본 방침에 명시한 목적 범위 안에서 처리하며, 법령에 근거가 있거나 이용자의 별도 동의가 있는 경우를 제외하고 제3자에게 제공하지 않습니다.

다만 원격관리 서비스의 특성상 구성원이 승인하거나 연결한 원격관리자에게 다음 정보가 제공될 수 있습니다.

10. 이용자와 법정대리인의 권리

이용자와 법정대리인은 언제든지 개인정보 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 요청은 앱 설정, 고객지원, 개인정보 보호책임자 연락처를 통해 할 수 있습니다.

다만 다른 이용자의 권리 보호, 법령상 보관 의무, 결제/분쟁 처리, 보안 로그 보전이 필요한 경우 일부 요청이 제한될 수 있습니다. 원격관리 연결 중인 구성원은 계정 탈퇴 전 연결 해제 절차가 필요할 수 있습니다.

11. 자동 수집 장치 및 추적

회사는 광고 목적의 제3자 추적을 계획하지 않습니다. 앱 안정화와 보안, 기능 제공을 위해 앱 설치 ID, 기기 ID, 푸시 토큰, 접속 로그, 오류 로그가 자동으로 생성될 수 있습니다. 또한 서비스 품질 개선을 위해 앱 기능 사용 이력(내용이 포함되지 않은 사용 횟수)이 수집될 수 있습니다. 웹뷰 또는 웹페이지에서 쿠키를 사용하는 경우 목적, 보관 기간, 거부 방법을 별도로 안내합니다.

  6. 보안 취약점 점검, 로그 모니터링, 장애 대응 절차

13. 위치정보 처리에 관한 사항

회사는 아래 두 가지 방식으로 개인위치정보를 처리할 수 있습니다. 두 방식 모두 상시 위치 추적이 아니라 그때마다 현재 위치를 1회 처리합니다.

13.1 요청형 현재 위치 (원격관리자가 요청)

구성원은 기기별로 사용 거부, 동의(매번), 자동 응답 중 하나를 선택할 수 있습니다. 동의(매번)에서는 요청자와 목적을 확인하고 승인한 경우에만, 자동 응답에서는 사전에 고지·확인한 범위에서 요청마다 현재 위치를 처리합니다. 자동 제공 후에는 제공받는 자·목적·시각을 앱 알림으로 안내합니다. 사용 거부에서는 요청을 처리하지 않습니다.

  1. 처리 목적: 구성원이 선택한 처리 방식에 따른 현재 위치를 원격관리자에게 표시
  2. 처리 항목: 현재 위치 좌표, 요청자/수신자, 요청 시각, 처리 방식 선택, 승인/거절/만료/표시 상태
  3. 보유 기간: 위치 좌표는 표시 완료 또는 임시 보관 시간(5분) 만료 후 삭제, 요청 메타데이터는 감사와 분쟁 대응을 위해 90일 보관(그중 위치 이용·제공사실 확인자료는 180일, 13.3)
  4. 제공: 해당 요청을 생성한 연결된 활성 원격관리자에게 표시. 자동 응답 선택 시에도 요청마다 제공 사실을 통보
  5. 이용자 권리: 위치정보 처리 동의 철회, 일시 중지, 열람, 정정, 삭제 요청 가능
  6. 법정대리인 권리: 만 14세 미만 아동의 개인위치정보 처리에 대해 법정대리인이 권리를 행사할 수 있음

13.2 구성원 주도 현재 위치 제공 (구성원이 직접 전송)

원격관리자의 요청이 없어도, 구성원이 직접 실행할 때 현재 위치를 1회 측정해 연결된 원격관리자에게 제공하는 기능입니다. 이 기능은 요청형과 별개의 동의를 받은 경우에만 동작하며, 동의를 철회하면 비활성화됩니다.

  1. 처리 목적: 구성원이 선택하거나 연결된 전체 원격관리자에게 본인의 현재 위치 제공
  2. 처리 항목: 현재 위치 좌표, 정확도, 측정 시각, 제공받는 자, 제공 시각, 성공/실패 상태
  3. 제공받는 자: 구성원이 선택한 원격관리자 또는 연결된 모든 활성 원격관리자 (구성원이 전송 직전 대상을 확인)
  4. 보유 기간: 위치 좌표는 원격관리자의 표시 완료 또는 임시 보관 시간(5분) 만료 시 삭제, 운영 메타데이터는 90일 보관(그중 위치 이용·제공사실 확인자료는 180일, 13.3)
  5. 제공 통보: 제공할 때마다 제공받는 자·목적·시각을 구성원에게 알림과 서비스 내 기록으로 통보
  6. 이용자 권리: 능동 제공 동의의 철회, 열람, 정정, 삭제 요청 가능
  7. 법정대리인 권리: 만 14세 미만 아동은 법정대리인 동의·확인 절차를 거친 뒤에만 이 기능을 사용할 수 있으며, 법정대리인이 권리를 행사할 수 있음

13.3 공통 사항

요청 메타데이터 가운데 위치정보 수집·이용·제공사실 확인자료(제공받는 자, 제공 시각, 처리 상태 등 — 좌표 제외)는 위치정보의 보호 및 이용 등에 관한 법률에 따라 최소 6개월(180일) 보관합니다.

회사는 지속적 위치 추적이나 위치 기반 광고를 제공하지 않으며, 긴급구조 목적의 위치 제공 기능(응급구조 대체 서비스)은 제공하지 않습니다. 구성원 주도 위치 제공도 긴급구조를 대체하지 않으며, 위급 상황에서는 긴급 전화를 이용해야 합니다.
